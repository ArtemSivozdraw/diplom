 
# Інструкція з використання програми

## Перелік пристроїв необхідних для роботи програми

- Пульт керуваня (бажанно радіоапаратура по типу RadioMaster Boxer, але програма може працювати і з звичайними джойстиками).
- ewfr радіоприймач з usb type-c конектором, або usb (має збігатися з частотами вашого дрона).
- ELRS радіо передавач. (має збігатися з частотами на вашому дроні)(можна використовувати і elrs приймач, але тоді його потрібно буде прошити як передавача).
- ttl_to_usb convertor, для elrs передавача. (якщо передавач має usb вихід тоді конвертор непотрібен).

## Попередні налаштування

1. Прошийте ELRS передавач та приймач на дроні, однаковою bind фразою. Використовуйте для цього ExpressELRS Configurator.
2. Запустіть окремо сервер використовуючи обидва файли з папки Server.
3. За потреби, встановіть драйвери ttl адаптера, якщо приймач не розпізнається як COM порт в диспечері пристроїв.
4. Впевністься що сервер досяжний з боку пілота та дрона.

## Засоби компіляції

Обовязково перед компіляцією програми потрібно в папці з Cmake файлом створити папки libs та build. Після чого виконати наступні пункти:
- У папку libs потрібно встановоти бібліотеку opencv з офіційного сайту <https://opencv.org>.
- Потрібно встановити "visual studio build tools 2022".
- За допомогою "Developer Command promt for VS 2022", зкоміпілювати реліз версію програми.
- Перенести з бібліотеки opencv файл "opencv_world4120.dll", його розташування "opencv\build\x64\vc16\bin", до .exe файлу зкомпільованої програми, папка Release.

## Запуск програми з сторони дрона

1. Знайдіть підкючений відеоприймач за допомогою команди "cam list".
2. Запустіть камеру використовуючи "cam start [ID]".
3. Використайте "serial start [COM_ID] [baud_rate]", для початку роботи передавача. Якщо бауд рейт і ком порт задано правильно, прийде повідомлення про успішне підключення ком порту. COM_ID можна знайти в диспечері пристороїв ("COM1", або "COM4"). Стандартне значення boud_rate = 115200, але іноді може бути 400000, або 420000.
4. Подайте живлення на дрон і дочекайтеся поки в логах не виведеться повідомелння про отримання телеметрії від батареї. Це означає що приймач і передавач успішно з'єдналися один з одним.
5. Введіть "connect drone [Server_IP]:80", при успішному під'єднання до сервера, має прийти повідомлення з id сесії.
6. Скопіюйте id за допомогою "cpid" і передайте пілоту. !!! НЕ ПЕРЕДАВАЙТЕ ID СТОРОНІМ ОСОБАМ !!!
7. Чекайте під'єднання пілота. Якщо він під'єднається успішно, ви побачите значення rrt - затримка, та поточне значення каналів керування його пульта.

## Запуск програми з сторони пілота

1. Використовуючи "joy list" знайдіть id свого пристроя керування.
2. Ввівши "joy calib [ID]" почніть калібрування пристрою.
3. Під час калібрування, до каналу, який запитує програма прив'язується тий канал який мав найбільше відхилення при прослуховувані. Тобто коли питають назначте вісь X, потрібно поводити від мінімального до масимального ту вісь, яку хочете назначити на X. Таким чином, потрібно назначити 10 каналів керування. Якщо ви якісь канали не використовуєте, канал можна пропустити ввівши skip.
4. Введіть "connect pilot [server_id]:80 [drone_id]", якщо все введено правильно, одразу з'явиться картинка з дрона і ви зможете керувати ним своєю апаратурою.
